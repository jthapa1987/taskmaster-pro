# Taskmaster Pro Edition

A simple drag‑and‑drop task manager built with HTML, CSS, Bootstrap, jQuery, and jQuery UI. Create tasks, edit them inline, move them 
across lists, and track deadlines with automatic auditing.

## Live Demo
https://jthapa1987.github.io/taskmaster-pro/

## Features
- Add tasks with description + due date  
- Drag and drop between To Do, In Progress, In Review, Done  
- Inline editing for text and dates  
- Datepicker with future‑date validation  
- Trash dropzone to delete tasks  
- Auto‑audit overdue tasks  
- Saves everything in LocalStorage  

## Tech Stack
HTML • CSS • Bootstrap • jQuery • jQuery UI • LocalStorage
